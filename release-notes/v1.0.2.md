# IDreamOfEasy Legacy 1.0.2

A compatibility, correctness, and scheduler-hardening release for **Paper 26.2 / Minecraft 1.21.11+** and **Slimefun Legacy**.

The attached `SF_IDreamOfEasy_Legacy_v1.0.2.jar` is the direct server JAR. No extraction is required, and **GuizhanLibPlugin is not required**.

## Highlights

- Migrated the addon away from deprecated Slimefun storage, ticker, energy, research, recipe, metadata, durability, biome, and chat APIs.
- Removed IDreamOfEasy source deprecation warnings against the current Paper 26.2 + Slimefun Legacy build target.
- Added Paper/Folia-aware region, global-region, and entity scheduler usage for Alarm Clock, Magnetoid, Lava Boat, Stack Dispenser, and Radiation Absorber tasks.
- Declared `folia-supported: true` and added CI checks that reject known legacy/global-scheduler regressions.
- Hardened CI to build against the latest released Slimefun Legacy JAR and validate the finished plugin JAR before publishing it.

## Gameplay and correctness fixes

- **Player Hopper:** fixed partial-transfer accounting that could duplicate items; now moves an exact amount and consumes power only when a transfer succeeds.
- **Supply Hopper:** fixed partial transfers so moved items are accounted for correctly and power is charged only when items actually move.
- **Electric Shearer:** now consumes its configured energy cost when sheep are actually sheared.
- **Electric Cable:** fixed the effective double-energy requirement before damage and stopped particle-location mutation across multiple targets.
- **Stack Dispenser:** now owns the dispense operation cleanly, moves one exact stack on the block's region, and avoids the old item-loss/next-slot edge cases.
- **Magnetoid:** fixed task validity logic for offline/spectator players, moved temporary item markers to persistent data, and moved entity work to Paper schedulers.
- **Radiation Absorber:** replaced shared/unsafe countdown state with per-player protection sessions, modern energy access, concurrent-safe state, and region/entity scheduling.
- **Lava Boat:** uses persistent data instead of legacy metadata, modern Dark Oak boat entities, and entity-scheduler delayed work while retaining the combustion fix.
- **Alarm Clock:** uses Paper's modern async chat event and entity scheduler; timers can resume correctly when a player reconnects.
- **Biome Compass:** uses Paper's biome registry and nearest-biome API instead of removed enum iteration/brute-force scanning.
- **Divine Idol:** uses modern item damage and Adventure display-name APIs.
- **Electric Smoker / Blast Furnace:** use modern recipe choices instead of deprecated cooking-recipe input access.
- **Chisel, Jawn, Wister Shears, Terrabores, Stack Dispenser:** migrated from the legacy `BlockStorage` facade to current Slimefun Legacy storage APIs.

## Compatibility

- Paper 26.2: primary target
- Purpur 26.2: Paper-compatible target
- Folia: secondary/experimental target; scheduler-sensitive addon code has been migrated to Paper/Folia scheduler APIs and the plugin is marked Folia-supported
- Java: compiled for Java 21; CI validates on Java 25
- Slimefun: Slimefun Legacy
- GuizhanLibPlugin: not required
